# Дизайн «Послесвечения» — направление «Свет звезды»

Выбрано из четырёх вариантов: «Тёмная комната», «Бумажный дневник», «Свет звезды», «Арт-журнал».
Метафора — из концепции: свет звезды доходит до нас, когда она уже погасла. **Каждый день — звезда, которая продолжает светить.**

## Принципы
1. **Ночь как холст.** Интерфейс тёмный и тихий, цвет появляется только из дней — палитра каждой открытки берётся из её фото.
2. **Свечение вместо теней.** Глубину дают концентрические ореолы с прозрачностью, без размытия и теней.
3. **Пульс под музыку.** Ореолы дышат в такт песни: `--beat = 60 / bpm` с, сила пульса `--amp` — от энергии дня.
4. **Одна янтарная кнопка на экран.** Акцент `glow-400` — только для главного действия («Зажечь день», «+»).
5. **Объяснимость видна.** «Почему так» — всегда в одно касание от открытки.

## Открытка дня (`Postcard`)
**Постоянные элементы** — делают ленту цельной:
дата-штамп слева сверху · рамка-паспарту · главный отпечаток в ореолах (`GlowOrb`) · рукописная подпись (дословно из текста) · название внизу · плёночное зерно.

**Переменные элементы** — из паспорта (`src/lib/visual.ts → visualParams`):
| Ось | Что меняет в прототипе |
|---|---|
| Темп (BPM) | скорость пульса ореолов и эквалайзера |
| Энергия | амплитуда пульса |
| Близость | размер главного отпечатка, глубина виньетки |
| Плотность | число отпечатков-спутников (коллаж) |
| Эпоха | сила зерна |
| Приёмы | фоновый слой `StyleLayer`: мазки Моне, поля Ротко, геометрия Кандинского, «ма», засвет плёнки, коллаж, вихрь Тёрнера, точки поп-арта — смешиваются по весам |

## Экраны
| Маршрут | Экран |
|---|---|
| `/` | **Небо года** — каждый день как точка-звезда своей палитры, фильтры, «В этот день», недавние открытки |
| `/new` | **Новая запись** — текст, фото (остаются на устройстве), песня, «Зажечь день» → анимация зажигания |
| `/day/[id]` | **Папка дня** — открытка, плеер фрагмента, «Почему так» (радар паспорта, объяснения, смесь приёмов, палитра), «Послушать», запись |
| `/feed` | **Лента** — оглавление дней открытками |

## Особенности, которых нет у других
| Функция | Где | Как работает |
|---|---|---|
| **А что если…** (ремикс) | `/day/[id]/remix`, кнопка на экране дня | Меняешь песню, свет фото или настроение текста → `src/lib/rules.ts` пересчитывает паспорт и веса приёмов, открытка перерисовывается, «Что изменилось» объясняет разницу, радар показывает было/стало |
| **Созвездия** | Небо → вкладка «Созвездия» | `src/lib/constellations.ts`: дни с близкими паспортами (8 осей) соединяются, созвездия и их названия выводятся автоматически, карта — проекция PCA |
| **Свет доходит позже** | Новая запись → «Когда зажечь», блок «Свет в пути» на небе, `/entry/[id]` | Запись запечатывается до даты, на небе виден её путь; демо-кнопка «Перемотать время» показывает прилёт. Демо-письмо — `src/data/letters.ts` |
| **Настоящая запись** | `/new` → `/entry/[id]` | Палитра извлекается из твоих фото, текст разбирается словарём (временная замена LLM, `src/lib/text-mood.ts`), название и подпись — из твоих слов; всё хранится только в браузере |
| **Озвучка** | «Послушать» на экране дня | Web Speech API: голос по валентности × энергии, скорость — от темпа песни |

## Что пока заглушка
- Текст разбирается словарём корней, а не языковой моделью; песни — каталог из 10 треков без настоящего поиска и анализа аудио.
- «Архивные» звёзды на карте созвездий сгенерированы вокруг демо-дней (`src/data/archive.ts`).
- Плеер без звука, экспорт видео показывает подсказку.
- `StyleLayer` — SVG-эскизы приёмов. В рабочей версии их заменят GLSL-фильтры (см. `docs/PLAN.md`, этап 3).
